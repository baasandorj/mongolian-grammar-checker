# Монгол хэлний зөв бичих дүрмийн шалгагч

[English](README.md) · **Монгол**

Монгол кирилл бичвэрийг (ном, гар бичмэл, нийтлэл) **«Монгол хэлний зөв бичих дүрмийн журамласан толь»** (ХБҮЗ, 2018)-иар шалгадаг Claude skill болон Python скриптүүд. Алдааны тайлан, хүсвэл засвартай хуулбар гаргана.

Хоёр янзаар ашиглаж болно:

1. **Claude skill байдлаар.** Claude скриптүүдийг ажиллуулж, бичвэрийг [SKILL.md](SKILL.md) дахь дүрмийн лавлахын дагуу гараар уншиж, худал илэрцийг шүүгээд тайлан бичнэ.
2. **Гараар.** Python скриптүүдийг өөрөө командын мөрөөс ажиллуулна.

## Хавтасны бүтэц

## Шаардлага

- **Python 3.8 буюу түүнээс дээш.** `.md`, `.txt` файлд нэмэлт сан хэрэггүй.
- **python-docx** — `.docx` файлд. `check_text.py` үүнгүйгээр ч `.docx` уншина, гэхдээ гарчиг ялгах, хүснэгт уншихгүй. `apply_fixes.py`-д `.docx`-ийн хувьд заавал хэрэгтэй.

  ```bash
  pip install python-docx
  ```

- **pdftotext** (Poppler-ийн бүрэлдэхүүн) — `.pdf` файл уншихад.

  ```bash
  brew install poppler            # macOS
  sudo apt install poppler-utils  # Debian/Ubuntu
  ```

## Claude skill байдлаар ашиглах

### Суулгах

Skill нь хавтас бүхэлдээ: `SKILL.md` болон `scripts/`, `data/`, `references/`. Зөвхөн `SKILL.md`-г суулгавал Claude дүрмийн лавлахаар ажиллана, гэхдээ толь бичгийн өгөгдөл, автомат шалгагчгүй.

- **Claude Code:** хавтсыг skills хавтас руу хуулах буюу холбоос үүсгэнэ:

  ```bash
  # бүх төсөлд
  ln -s "$PWD" ~/.claude/skills/mongolian-grammar-checker
  # эсвэл зөвхөн нэг төсөлд
  mkdir -p .claude/skills && cp -R . .claude/skills/mongolian-grammar-checker
  ```

- **Claude.ai / Claude desktop апп:** хавтсыг zip болгож (`SKILL.md` хавтасныхаа дээд түвшинд байхаар) **Settings → Capabilities → Skills** хэсэгт оруулна.

### Хэрэглэх

Файлаа хавсаргах буюу замыг нь зааж, энгийн үгээр хүснэ:

- «энэ номын алдааг шалгаад өг»
- «2-р бүлгийн зөв бичгийн алдааг засаад засвартай хувийг гаргаж өг»
- "Proofread this Mongolian chapter and give me a report"

Claude дараах дарааллаар ажиллана:

1. файлыг хуулж, хуулбар дээр ажиллана (эх файл өөрчлөгдөхгүй);
2. `check_text.py`-г ажиллуулж, давхардсан илэрцийг хасаж тоолно;
3. эргэлзээтэй үгийг `lookup.py`-аар тольд тулгана;
4. бичвэрийг бүхэлд нь дүрмийн лавлахын дагуу гараар уншина;
5. монгол хэлээр тайлан бичнэ: байршил, бичигдсэн, зөв хэлбэр, дүрэм (§ дугаар эсвэл толийн толгой үг), товч тайлбар;
6. хүсвэл `apply_fixes.py`-аар засвартай хуулбар гаргаж, дахин шалгана.

Эргэлзээтэй засвар оруулах, баатрын яриа дахь аялга, ярианы хэлбэрийг засах, найруулгын санал өгөхөөс өмнө Claude танаас асууна. Оноосон нэр, эшлэл, зориуд гажуудуулсан үгийг алдаа гэж тоолохгүй.

Skill-д байнгын тохиргоо заах бол (жишээ нь «энэ цувралын гарчгийн эцэст цэг тавьдаггүй») Claude-д хэлээрэй; тэр `SKILL.md`-ийн «Сургамж» хэсэгт нэг мөр нэмэхийг санал болгоно.

## Скриптийг гараар ажиллуулах

Бүх жишээг хавтасны үндсэн түвшнээс ажиллуулна гэж үзэв. `-I` (тусгаарлагдсан горим) тавихыг зөвлөж байна — ингэснээр Python одоогийн хавтаст байгаа илүү модулийг ачаалахгүй.

### 1. Файл шалгах: `check_text.py`

```bash
python3 -I scripts/check_text.py ном.docx --json findings.json --md findings.md
```

| Сонголт | Утга |
|---|---|
| `PATH` | Оролтын файл: `.docx`, `.md`, `.txt` эсвэл `.pdf` |
| `--json FILE` | Илэрцийг JSON-оор хадгална (`apply_fixes.py`-ийн оролт) |
| `--md FILE` | Markdown хүснэгт тайлан хадгална |
| `--no-unknown` | Тольд үндэс нь олдоогүй үгийг мэдээлэхгүй |
| `--max-unknown N` | Тольд олдоогүй үгийн дээд тоо (анхдагч 300) |

`--json`, `--md` аль нь ч өгөөгүй бол Markdown тайланг дэлгэцэд хэвлэнэ.

**Түвшин:**

- **алдаа** — дүрэм тодорхой зөрчигдсөн (бэ/вэ, уу/юу, руу/луу, ы/ий, ъ/ь, гээгдэх эгшиг, дахь/дэх, түгээмэл алдааны жагсаалт…);
- **шалгах** — магадгүй алдаа, орчинд нь нягтал (эгшиг зохицол, тогтворгүй н, том үсэг…);
- **мэдээлэл** — хэв зүй (зай, хашилт) болон тольд олдоогүй үг (үсгийн алдаа байж болзошгүй).

**Байршил** нь `.docx`-д `догол мөр:багана`, `.md`, `.txt`, `.pdf`-д `мөр:багана`. Дугаарлалт 1-ээс эхэлнэ.

Гаралтын жишээ:

```text
| № | Түвшин | Байршил | Олдсон  | Санал   | Дүрэм       | Тайлбар                            |
|---|--------|---------|---------|---------|-------------|------------------------------------|
| 1 | алдаа  | 3:4     | гэр рүү | гэр лүү | Дүрэм §49.7 | р, рь-ээр төгссөн үгэнд -луу/-лүү  |
| 2 | алдаа  | 3:8     | рүү     | лүү     | §49.7       | р, рь-ээр төгссөн үгэнд -луу/-лүү… |
```

JSON-ы нэг илэрц:

```json
{"para": 3, "col": 4, "found": "гэр рүү", "suggest": "гэр лүү",
 "rule": "Дүрэм §49.7", "severity": "алдаа", "message": "…", "context": "…"}
```

**Анхаарах зүйл:**

- Нэг алдааг хоёр дүрэм давхар барьж болно (дээрх 1, 2-р мөр). Тоолохоосоо өмнө давхардлыг хас; үүнд зориулсан богино скрипт [SKILL.md](SKILL.md)-ийн 2-р алхамд бий.
- `suggest` заримдаа хоосон байна — «сэжигтэй, гэхдээ засвар тодорхойгүй» гэсэн үг. Үгийг тольд тулгаж өөрөө шийд.
- Скрипт зөвхөн механикаар илрэх алдааг олно. Бичвэрийг өөрөө унших шаардлагатай хэвээр.

### 2. Үг лавлах: `lookup.py`

```bash
python3 -I scripts/lookup.py гэр хүүхдийн станц   # нэг буюу хэд хэдэн үг
python3 -I scripts/lookup.py --code I.17.1        # хувиллын кодын албан ёсны жишээ
python3 -I scripts/lookup.py --grep '^бөмбө'      # регексээр толгой үг хайх
```

Үг бүрийн хувьд:

- толийн таарсан толгой үг (хувиллын код, хэрэглээ, хэл зүйн ангилал, тайлбар);
- гадаад үг бол түүний хувилсан хэлбэрүүд;
- түгээмэл алдаа бол анхааруулга, зөв хэлбэрийн хамт;
- толгой үг биш бол хамгийн урт таарсан үндэс, тэр үндэс хэрхэн хувилах жишээ;
- ойролцоо бичлэгтэй үгс (үсгийн алдааны магадгүй засвар).

Хувиллын код (жишээ нь `I.5.4`) нь эгшиг гээгдэх эсэх, тогтворгүй н байгаа эсэх зэргийг албан ёсоор заана. Тийн ялгалын хэлбэр эргэлзээтэй бол `--code`-оор жишээг нь хар.

### 3. Засвар оруулах: `apply_fixes.py`

```bash
python3 -I scripts/apply_fixes.py ном.docx approved.json ном_засвар.docx
```

`approved.json` нь `check_text.py --json`-ийн гаргадаг бүтэцтэй засварын жагсаалт. Ихэвчлэн `findings.json`-ийг хуулж, санал нийлэхгүй мөрийг устгаж, шаардлагатай бол `suggest`-ийг нөхөж засаад, гараар олсон алдаагаа нэмнэ:

```json
[
  {"para": 3,  "col": 4, "found": "гэр рүү", "suggest": "гэр лүү"},
  {"para": 12,           "found": "багшын",  "suggest": "багшийн"},
  {                      "found": "МУИС-ын", "suggest": "МУИС-ийн"}
]
```

| Өгсөн талбар | Юуг солих |
|---|---|
| `para` + `col` | зөвхөн тэр нэг тохиолдол |
| зөвхөн `para` | тэр догол мөр/мөр дэх бүх тохиолдол |
| аль нь ч үгүй | файл даяарх бүх тохиолдол |

- Зөвхөн бүтэн үгийг солино; эхний том үсгийг хадгална.
- `suggest` хоосон мөрийг алгасна.
- Гаралтын зам оролтоос ялгаатай байх ёстой. Эх файлыг хэзээ ч дарж бичихгүй.
- `.docx`-д run бүрээр солих тул хэлбэржилт хадгалагдана. Солих үг хэд хэдэн run-д хуваагдсан бол тэр догол мөрийн хэлбэржилт нэгдэж, дугаарыг нь хэвлэнэ — шалгаж үзээрэй.
- `.pdf`-д засвар оруулах боломжгүй. Эхлээд `.docx` эсвэл `.txt` болго.
- Засвар оруулсны дараа шинэ файлыг `check_text.py`-аар дахин шалгаж үлдэгдлийг хар.

### Гараар хийх бүтэн дараалал

```bash
S=scripts
python3 -I $S/check_text.py ном.docx --json findings.json --md findings.md
# findings.md-г уншиж, эргэлзээтэй үгийг лавлана
python3 -I $S/lookup.py хаалга хаалганы
# findings.json -> approved.json хуулж, зөвшөөрсөн засвараа л үлдээнэ
python3 -I $S/apply_fixes.py ном.docx approved.json ном_засвар.docx
python3 -I $S/check_text.py ном_засвар.docx --md remaining.md
```

## Өгөгдлийн файлууд

Бүх өгөгдлийн файл UTF-8, таб-аар тусгаарласан, эхний мөр нь багануудын нэр. Хүснэгт засварлагчаар нээх буюу `grep`-ээр хайж болно:

```bash
grep $'^станц\t' data/dictionary.tsv
grep 'гэр' data/common_errors.tsv
```

Шалгагчид шинэ түгээмэл алдаа таниулах бол `data/common_errors.tsv`-д мөр нэмнэ:

| Багана | Утга |
|---|---|
| `буруу` | буруу хэлбэр |
| `зөв` | зөв хэлбэр (хэд хэдэн хувилбарыг ` \| `-ээр тусгаарлана) |
| `төрөл` | `алдаа` → **алдаа** түвшинд; бусад (жишээ нь `анхаар`) → **шалгах** түвшинд |
| `тааруулах` | `бүтэн`: зөвхөн бүтэн үг; `угтвар`: эхлэлээр нь таарна, ингэснээр хувилсан хэлбэр ч баригдана (зөвхөн 6-аас дээш үсэгтэй дан үгэнд) |
| `тайлбар` | тайланд гарах товч тайлбар |
| `эх сурвалж` | эх сурвалж: толийн хуудас/толгой үг эсвэл дүрмийн § |

## Хязгаарлалт

- Энэ бол туслах хэрэгсэл, эцсийн шийдвэр биш. Дүрэмд суурилсан шалгалт зарим алдааг алгасаж, заримдаа худал анхааруулга өгнө — ялангуяа оноосон нэр, баатрын яриа, аялга, гарчиг, дугаарласан жагсаалт, ≈870-аас бусад гадаад нэр томьёонд.
- Зөвхөн зөв бичих дүрэм, цэг тэмдгийг шалгана; найруулга, агуулгыг шалгахгүй.
- Монгол бичиг (уйгаржин)-ийг дэмжихгүй.
- 2018 оноос хойшхи дүрмийн өөрчлөлтийг [toli.gov.mn](https://www.toli.gov.mn)-ээс шалгана уу.
